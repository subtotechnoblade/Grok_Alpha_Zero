# Inference only on TensorRT / CUDA. NVIDIA GPU required. Windows or linux / WSL.
# Gives TensorrtExecutionProvider AND CUDAExecutionProvider.
# No tensorflow, so this consumes an existing model.onnx rather than producing one.
#
# Best option for larger models: on gomoku, TensorRT fp16 is ~3x DirectML at
# batch 32 and fp16 buys 2.4x over fp32. On connect4 the model is too small to
# benefit and DirectML wins below batch ~28.
#
# DO NOT pass --only-binary=:all: with this file. tensorrt-cu12 is an sdist stub
# that pulls the real tensorrt_cu12_libs / tensorrt_cu12_bindings wheels, so
# that flag makes it fail with "no matching distribution".
#
#   pip install -r requirements-inference-tensorrt.txt

# self play writes its dataset with h5py, drop it if you only run play.py

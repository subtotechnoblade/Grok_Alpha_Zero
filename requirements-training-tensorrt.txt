# Training with TensorRT / CUDA self play inference. NVIDIA GPU required.
# Works on windows and on linux / WSL.
#
# Gives you TensorrtExecutionProvider AND CUDAExecutionProvider, so this covers
# both train_config["use_tensorrt"] = True and False.
#
# The nvidia CUDA and cuDNN runtimes come from the onnxruntime-gpu [cuda,cudnn]
# extras, so there is no separate CUDA Toolkit install and no admin rights
# needed. Verified working with CUDA runtime 12.9 and cuDNN 9.24 even though the
# ORT docs list 12.0-12.8.
#
# DO NOT pass --only-binary=:all: with this file. tensorrt-cu12 is an sdist stub
# that pulls the real tensorrt_cu12_libs / tensorrt_cu12_bindings wheels, so
# that flag makes it fail with "no matching distribution".
#
#   pip install -r requirements-training-tensorrt.txt
